### Задание 1. Реализация многопоточной программы для вычисления суммы элементов массива

#### Вариант 2. Использование ExecutorService для разбиения массива
Суть: Разделение массива на равные части, каждую из которых обрабатывает отдельный поток из пула `ExecutorService`. Главный поток суммирует результаты после завершения всех вычислений.

#### Класс BinaryTree (Базовая структура)
Внутренний класс Node: Дерево строится из узлов. Каждый узел `Node` содержит целочисленное значение `value`, а также ссылки на левого (`left`) и правого (`right`) наследников.

Добавление элементов (метод insert): Публичный метод вызывает приватный рекурсивный метод. Если текущий узел пуст (`null`), создается новый узел. Если вставляемое значение меньше значения текущего узла, алгоритм рекурсивно переходит в левое поддерево (`root.left`), если больше — в правое (`root.right`). Дубликаты игнорируются.

Поиск элементов (метод search): Работает рекурсивно. Если искомое значение равно значению текущего узла, возвращается `true`. Если оно меньше — поиск продолжается в левой ветви, если больше — в правой. При достижении `null` возвращается `false`.

Тестирование системы: В методе `main` инициализируется дерево (элементы 50, 30, 70, 20, 40, 60, 80) и проверяется присутствие элементов (для 40 вернется `true`, для 90 — `false`), что подтверждает корректность связей.


### Задание 2. Реализация многопоточной программы для поиска наибольшего элемента в матрице

#### Вариант 2. Использование ExecutorService для разбиения матрицы
Суть: Матрица разделяется на равные части между потоками из пула `ExecutorService`. После завершения их работы главный поток сравнивает локальные максимумы для нахождения наибольшего элемента.

#### Алгоритмы обхода дерева (DFS)
Инфиксный обход (inOrderTraversal): Рекурсивно обходит левое поддерево, обрабатывает текущий узел, затем правое поддерево. Для бинарного дерева поиска этот метод выполняет сортировку элементов по возрастанию.

Прямой обход (preOrderTraversal): Сначала обрабатывает текущий узел, после чего рекурсивно переходит к левому и правому поддеревьям. Используется для клонирования или сериализации структуры.

Обратный обход (postOrderTraversal): Рекурсивно проходит левую и правую ветви, и в самом конце обрабатывает корневой узел. Применяется при удалении дерева из памяти или вычислении постфиксных математических выражений.

Тестирование системы: В методе `main` последовательно вызываются все три метода обхода для демонстрации изменения порядка вывода чисел в консоль.


### Задание 3. Синхронизация работы грузчиков на складе

#### Вариант 2. Реализация интерфейса Runnable через ExecutorService
Суть: Моделирование одновременного переноса товаров тремя грузчиками (класс `LoaderRealization`, реализующий `Runnable`) с ограничением суммарного веса в 150 кг. При достижении лимита выполняется отправка и разгрузка. Управление потоками осуществляется через `ExecutorService`.

#### Анализ метрик и поиск экстремумов дерева
Поиск экстремумов (findMin и findMax): Метод `findMin` движется строго влево по ссылкам `node.left` до упора, так как наименьший элемент всегда находится в крайнем левом узле. Метод `findMax` аналогично движется по ссылкам `node.right` в крайнюю правую точку для поиска максимума.

Подсчет количества узлов (countNodes): Рекурсивно вычисляет размер дерева. Для любого узла сумма элементов равна 1 (текущий узел) плюс количество узлов в его левом и правом поддеревьях.

Определение глубины дерева (maxDepth): Рекурсивный алгоритм находит длину самого длинного пути от корня до листа. Метод вычисляет глубину левой и правой веток, выбирает максимальное значение через `Math.max()` и прибавляет 1 (текущий уровень).

Тестирование системы: В методе `main` выполняются замеры для построенного дерева. В консоль выводятся точные значения: минимальное число (20), максимальное (80), общее количество вершин (7) и высота дерева (3).
