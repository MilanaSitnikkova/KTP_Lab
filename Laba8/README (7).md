### Метаданные: DataProcessor
Пользовательская аннотация-маркер, предназначенная для разметки целевых методов обработки.
* Область видимости (Retention): `RUNTIME` — метаданные сохраняются в байт-коде и доступны во время работы программы для Reflection API.
* Цель применения (Target): `METHOD` — аннотировать можно только методы.
* Параметры: Содержит атрибут `description()` для логирования и документирования шагов конвейера.

### Модель данных (DTO): Item
Сущность, инкапсулирующая данные одной записи (ID, текстовое описание, числовое значение).
* Переопределяет метод `toString()` для сериализации объекта в текстовую строку CSV-формата.
* Содержит статический фабричный метод `fromString(String line)`, отвечающий за десериализацию (парсинг) строк, считанных из внешнего источника.

### Модули бизнес-логики (Процессоры)
Каждый процессор представляет собой изолированный класс, реализующий конкретный этап обработки данных с использованием декларативного подхода Stream API:
* `FilterProcessor`: Отвечает за условную выборку элементов. Использует оператор `.filter()`, отсекая записи, значение которых ниже установленного порога (меньше 100.0).
* `TransformProcessor`: Отвечает за модификацию данных. Использует оператор `.map()` для изменения состояния объектов в потоке (приведение текста к верхнему регистру и коррекция числового значения на +10%).
* `AggregationProcessor`: Отвечает за упорядочивание данных. Использует оператор `.sorted()` совместно с реверсивным компаратором для сортировки коллекции по убыванию.

### Контроллер конвейера: DataManager
Центральное ядро и оркестратор приложения. Выполняет следующие задачи:
* Файловый ввод-вывод (I/O): Потоковое чтение (`BufferedReader`) и запись (`BufferedWriter`) файлов-источников с обработкой исключений `IOException`.
* Динамическая интроспекция: Через метод `registerDataProcessor(Object processor)` регистрирует компоненты. В методе `processData()` с помощью Reflection API сканирует методы зарегистрированных объектов, находит те, что помечены аннотацией `DataProcessor`, и вызывает их через `Method.invoke()`.
* Управление многопоточностью: Инициализирует пул потоков `ExecutorService` с фиксированным количеством воркеров (`Executors.newFixedThreadPool(4)`). Каждый этап обработки оборачивается в асинхронную задачу `Callable`. Синхронизация между этапами и получение обновленного датасета обеспечиваются через блокирующий вызов `.get()` у объектов `Future`.

### Точка входа: Main
Класс-конфигуратор, который инициализирует жизненный цикл приложения. Он генерирует демонстрационный файл с входными данными, создает экземпляр `DataManager`, внедряет зависимости (регистрирует процессоры) и запускает последовательное выполнение конвейера.

### Алгоритм и жизненный цикл обработки данных
1. Инициализация: `Main` создает файл `source_data.csv` и регистрирует процессоры в `DataManager`.
2. Загрузка: `DataManager` считывает CSV-файл строка за строкой, парсит их через `Item.fromString()` и формирует исходную коллекцию `List` в оперативной памяти.
3. Сканирование и вызов: Контроллер обходит список процессоров. С помощью рефлексии извлекаются методы с аннотацией `DataProcessor`.
4. Асинхронное выполнение: Каждая найденная задача отправляется в пул потоков. Поток-воркер выполняет стрим-обработку над текущим состоянием коллекции. Главный поток ожидает завершения текущего этапа через `Future.get()`, после чего передает результат на вход следующему процессору (конвейерный паттерн).
5. Фиксация результатов: После прохождения всех этапов `DataManager` сохраняет финальное состояние коллекции в `processed_data.csv` и корректно высвобождает ресурсы, вызывая `executorService.shutdown()`.

### Технологический стек
* Язык разработки: Java (версия 8 и выше)
* Парадигмы: Объектно-ориентированное программирование (Инкапсуляция, Модульность), Функциональное программирование (Лямбда-выражения, Stream API).
* Метапрограммирование: Java Custom Annotations, Reflection API (`java.lang.reflect`).
* Конкурентность (Concurrency): Java Concurrency Utilities (`java.util.concurrent`), Thread Pools (`ExecutorService`), Асинхронные вычисления (`Callable`, `Future`).
