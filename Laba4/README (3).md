### Задание 1. Вычисление среднего арифметического массива

#### Класс ArrayAverage
Суть: Расчет среднего арифметического элементов строкового массива с защитой от сбоев.

Логика try-catch:
Внутренний блок изолирует `NumberFormatException` при вызове `Integer.parseInt()`. Ошибочные элементы (например, "abc") пропускаются, программа продолжает работу. Внешний блок перехватывает `ArrayIndexOutOfBoundsException`. Ошибка создана намеренно (условие `<= input.length` вместо `<`), при выходе за границы массива управление переходит во внешний `catch`.

Безопасность: Перед делением проверяется условие `if (count > 0)`. Если корректные числа есть, они приводятся к типу `double`, что предотвращает деление на ноль.

Кастомные исключения:
`EmptyArrayException`: Наследуется от `Exception`. Вызывается, если на вход передан пустой массив (длина равна 0).
`InvalidDataException`: Наследуется от `Exception`. Вызывается с помощью `throw`, если после обхода массива счетчик валидных чисел `count == 0` (нет данных для расчета).

### Задание 2. Чтение, обработка и запись матрицы в файл

#### Класс FileMatrixProcessor
Метод readMatrix: Построчно читает файл через `BufferedReader` и разбивает строки по пробелам (`split(" ")`). Конвертирует текст в числа через `Double.parseDouble`. Обрабатывает `FileNotFoundException` (файл отсутствует) и `NumberFormatException` (неверный формат данных).

Метод processMatrix: Обходит двумерный массив и считает сумму. Выбрасывает `EmptyArrayException`, если матрица пустая, и `InvalidDataException`, если в ней нет валидных чисел.

Метод writeResult: Записывает итоговое среднее арифметическое в файл через `BufferedWriter`. Возможные сбои диска изолируются в блоке `catch (IOException e)`.

Метод main: Запускает цепочку (чтение matrix.txt -> расчет -> запись result.txt). Весь процесс обернут в `try-catch` для перехвата и логирования ошибок.

### Задание 3. Кастомное исключение ввода

#### Класс CustomInputMismatchException
Суть: Собственный класс исключения для обработки некорректного пользовательского ввода вместо стандартного `InputMismatchException`.

Функционал: Программа считывает целое число с клавиатуры (`Scanner`). Если пользователь вводит не число (например, текст), программа перехватывает ошибку, генерирует `CustomInputMismatchException` и логирует информацию о выброшенном исключении в текстовый файл.
