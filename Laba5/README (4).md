### Задание 1. Поиск всех чисел в тексте

#### Описание задачи
Программа ищет все числа в заданном тексте с использованием регулярных выражений и выводит их на экран, обрабатывая возможные ошибки.

#### Классы кастомных исключений
 `InvalidMatrixSizeException`: Наследуется от `Exception`. Используется, когда структура или размерность считываемой матрицы нарушены (например, строки имеют разную длину). Передает описание ошибки в `super(message)`.
 `MatrixComputationException`: Наследуется от `Exception`. Служит для локализации ошибок непосредственно в процессе математических вычислений над элементами матрицы.

#### Использование в коде
Программа проверяет размеры строк при чтении файла. Если длина очередной строки не совпадает с длиной первой, генерируется `InvalidMatrixSizeException`. При расчете среднего арифметического любые непредвиденные вычислительные сбои перехватываются и оборачиваются в `MatrixComputationException`, изолируя проблемы от общих ошибок ввода-вывода (`IOException`).


### Задание 2. Проверка корректности ввода пароля

#### Описание задачи
Программа проверяет пароль на соответствие требованиям с помощью регулярных выражений: латинские буквы и цифры, длина от 8 до 16 символов, наличие хотя бы одной заглавной буквы и одной цифры.

#### Класс MatrixExceptionProcessor
Главная точка входа (метод main): Последовательно вызывает этапы обработки данных. Вся цепочка вызовов обернута в конструкцию `try-catch-finally`.

Обработка исключений (блоки catch):
 `FileNotFoundException`: Срабатывает, если файл `matrix.txt` отсутствует.
 `InvalidMatrixSizeException` и `EmptyArrayException`: Перехватывают нарушения геометрии матрицы или передачу пустого файла.
 `InvalidDataException` и `MatrixComputationException`: Изолируют ошибки парсинга текста в числа или математических расчетов.
 `IOException`: Базовый блок для остальных сбоев ввода-вывода.

Гарантированное выполнение (блок finally): Независимо от результатов расчета, программа обязательно выполняет блок `finally`, выводя в консоль техническую отметку «Завершение обработки матрицы».

### Задание 3. Поиск заглавной буквы после строчной

#### Описание задачи
Программа находит все случаи в тексте, когда сразу после строчной буквы идет заглавная без разделителей, и выделяет их знаками «!» с двух сторон.

#### Система валидации данных
 Иерархия исключений: Сочетание стандартных (`IOException`, `NumberFormatException`, `FileNotFoundException`) и собственных кастомных классов (`InvalidMatrixSizeException`, `MatrixComputationException`) для точечной локализации ошибок.
 Управление потоком: Использование конструкций `try-catch-finally`, одиночного и множественного перехвата исключений, а также контролируемой генерации ошибок через `throw`.

### Задание 4. Проверка корректности ввода IP-адреса

#### Описание задачи
Программа проверяет корректность ввода IP-адреса с помощью регулярных выражений: он должен состоять из 4 чисел от 0 до 255, разделенных точками.

#### Класс Stack (Стек)
Внутреннее устройство: Хранилище реализовано в виде массива строк `elements`. Начальная емкость `DEFAULT_CAPACITY = 10`. Переменная `top` указывает на индекс следующей свободной ячейки и отражает количество элементов.

Динамическое расширение (метод ensureCapacity): Если массив заполнен (`top == elements.length`), его емкость автоматически увеличивается в 2 раза с помощью `Arrays.copyOf()`.

Добавление и удаление (методы push/pop): Метод `push` помещает строку в `elements[top]` и делает `top++`. Метод `pop` уменьшает `top` на единицу, забирает значение, зануляет ячейку для предотвращения утечки памяти и возвращает строку. При пустом стеке выбрасывает `EmptyStackException`.

Вспомогательные методы: `peek()` возвращает верхний элемент (`elements[top - 1]`), `isEmpty()` проверяет равенство `top == 0`, `size()` возвращает текущее количество элементов (`top`).

Тестирование: В методе `main` создается объект стека, добавляются три строки, демонстрируется работа методов `peek()`, `pop()` в обратном порядке и контроль итогового размера.


### Задание 5. Поиск всех слов, начинающихся с заданной буквы

#### Описание задачи
Программа ищет в заданном тексте все слова, начинающиеся с определенной буквы, используя регулярные выражения, и выводит их на экран с обработкой ошибок.

#### Дополнительные методы Стека
 Поиск элемента (search): Перебирает массив с конца и возвращает позицию элемента относительно вершины (1 — для верхнего, 2 — для следующего). Если элемент не найден, возвращает -1.
 Вывод структуры (printStack): Печатает текущее содержимое массива в консоль для визуализации состояния памяти.

#### Логика инвертора строк (метод main)
 Посимвольный разбор: Каждый символ исходной строки преобразуется в строку через `String.valueOf()` и добавляется в стек методом `push`.
 Разворот строки: За счет принципа LIFO символы извлекаются методом `pop` в обратном порядке. Программа считывает их и склеивает в новую строку, пока `isEmpty()` не вернет `true`. В консоль выводится исходный текст и его зеркальное отображение.
