Задание 1. Создайте программу, которая находит и выводит все простые числа меньше 100.

Объяснение работы кода:
Запуск главного цикла: В методе main мы создаем цикл, который по очереди перебирает числа от 2 до 99 (строго меньше 100). 
Каждое число мы отправляем в созданную нами функцию isPrime. Если функция подтверждает, что число простое, мы выводим его в консоль через пробел.
Реализация функции проверки: Мы создаем метод isPrime, который принимает число n и проверяет, является ли оно простым. Внутри метода мы запускаем цикл, который ищет делители в диапазоне от 2 до $n-1$. 
Если исходное число делится на текущий шаг цикла без остатка (n % i == 0), то метод сразу возвращает false, так как число составное. 
Если цикл завершается и ни одного делителя не найдено, метод возвращает true.

Задание 2. Создайте программу, которая определяет, является ли введенная строка палиндромом.

Объяснение работы кода:
1.	Обработка входных данных: В методе main мы создаем цикл, который поочередно перебирает все строки, переданные в программу через аргументы командной строки args.
Каждую строку мы отправляем на проверку в созданный нами метод isPalindrome.
В зависимости от ответа программы мы выводим сообщение, является слово палиндромом или нет.
3.	Переворот строки: Мы создаем вспомогательный метод reverseString, который принимает строку и возвращает ее в перевернутом виде.
Для этого внутри метода мы запускаем цикл, который перебирает символы исходного слова с самого конца к началу и посимвольно собирает их в новую строку reversed.
5.	Реализация функции проверки: Мы создаем логический метод isPalindrome, который определяет, одинаково ли читается слово в обоих направлениях.
Внутри него мы сначала переворачиваем входящую строку с помощью нашего метода reverseString, а затем сравниваем получившийся результат с оригиналом через s.equals(reversed).
Если они полностью совпадают, метод возвращает true.
