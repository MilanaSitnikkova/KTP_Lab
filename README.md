### Задание 1. Создайте программу, которая находит и выводит все простые числа меньше 100.

#### Объяснение работы кода
Запуск главного цикла: В методе main мы создаем цикл, который по очереди перебирает числа от 2 до 99 (строго меньше 100). Каждое число мы отправляем в созданную нами функцию isPrime. Если функция подтверждает, что число простое, мы выводим его в консоль через пробел.

Реализация функции проверки: Мы создаем метод isPrime, который принимает число n и проверяет, является ли оно простым. Внутри метода мы запускаем цикл, который ищет делители в диапазоне от 2 до $n - 1$. Если исходное число делится на текущий шаг цикла без остатка (n % i == 0), то метод сразу возвращает false, так как число составное. Если цикл завершается и ни одного делителя не найдено, метод возвращает true.

### Задание 2. Создайте программу, которая определяет, является ли введенная строка палиндромом.

#### Объяснение работы кода
Обработка входных данных: В методе main мы создаем цикл, который поочередно перебирает все строки, переданные в программу через аргументы командной строки args. Каждую строку мы отправляем на проверку в созданный нами метод isPalindrome. В зависимости от ответа программы мы выводим сообщение, является слово палиндромом или нет.

Переворот строки: Мы создаем вспомогательный метод reverseString, который принимает строку и возвращает ее в перевернутом виде. Для этого внутри метода мы запускаем цикл, который перебирает символы исходного слова с самого конца к началу и посимвольно собирает их в новую строку reversed.

Реализация функции проверки: Мы создаем логический метод isPalindrome, который определяет, одинаково ли читается слово в обоих направлениях. Внутри него мы сначала переворачиваем входящую строку с помощью нашего метода reverseString, а затем сравниваем получившийся результат с оригиналом через s.equals(reversed). Если они полностью совпадают, метод возвращает true.

#### Класс Queue (Очередь на основе FIFO)
Структура: Односвязный список узлов Node (поля data и next). Ссылки на начало (head) и конец (tail) очереди, счетчик size.

Метод enqueue(item): Добавляет элемент в конец (tail). Если очередь пуста, head и tail указывают на один узел. При наличии элементов обновляет tail.next и смещает tail.

### Задание 2. Реализация многопоточной программы для поиска наибольшего элемента в матрице

#### Вариант 2. Использование ExecutorService для разбиения матрицы
Суть: Матрица разделяется на равные части между потоками из пула `ExecutorService`. После завершения их работы главный поток сравнивает локальные максимумы для нахождения наибольшего элемента.

#### Алгоритмы обхода дерева (DFS)
Инфиксный обход (inOrderTraversal): Рекурсивно обходит левое поддерево, обрабатывает текущий узел, затем правое поддерево. Для бинарного дерева поиска этот метод выполняет сортировку элементов по возрастанию.

Прямой обход (preOrderTraversal): Сначала обрабатывает текущий узел, после чего рекурсивно переходит к левому и правому поддеревьям. Используется для клонирования или сериализации структуры.

Обратный обход (postOrderTraversal): Рекурсивно проходит левую и правую ветви, и в самом конце обрабатывает корневой узел. Применяется при удалении дерева из памяти или вычислении постфиксных математических выражений.

Тестирование системы: В методе `main` последовательно вызываются все три метода обхода для демонстрации изменения порядка вывода чисел в консоль.
