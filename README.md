Задание 1. Поиск всех чисел в тексте
Кастомные исключения матриц
InvalidMatrixSizeException: Наследуется от Exception. Генерируется через throw, если при чтении файла нарушена геометрия матрицы (длина строк не совпадает).
MatrixComputationException: Наследуется от Exception. Изолирует вычислительные сбои во время математических расчетов от общих ошибок ввода-вывода.
Программа поиска чисел
Суть: Поиск числовых совпадений в тексте с помощью регулярных выражений (Pattern, Matcher) и обработка ошибок ввода/парсинга данных.

Задание 2. Проверка корректности ввода пароля
Класс MatrixExceptionProcessor
Метод main: Содержит цепочку вызовов этапов обработки матриц, обернутую в try-catch-finally.
Блоки catch: Обрабатывают FileNotFoundException (файл не найден), InvalidMatrixSizeException/EmptyArrayException (геометрия/пустой файл), InvalidDataException/MatrixComputationException (ошибки парсинга/вычислений) и базовый IOException.
Блок finally: Гарантированно выводит строку «Завершение обработки матрицы» для фиксации конца работы алгоритма.
Программа проверки пароля
Суть: Проверка пароля регулярным выражением на соответствие критериям: латиница и цифры, длина 8–16 символов, минимум одна заглавная буква и одна цифра.

Задание 3. Поиск заглавной буквы после строчной
Система валидации
Компоненты: Комбинация встроенных и кастомных исключений для локализации ошибок файловой системы и математики. Продемонстрирован контроль потока через генерацию ошибок (throw) и множественный перехват (try-catch-finally).
Программа модификации текста

Задание 4. Проверка корректности ввода IP-адреса
Класс Stack (Динамический массив)
Структура: Массив строк elements (дефолтно — 10 элементов) и указатель вершины top (LIFO).
ensureCapacity: Удваивает емкость массива через Arrays.copyOf(), если top == elements.length.
push(item): Добавляет элемент в elements[top] и инкрементирует top.
pop(): Декрементирует top, забирает значение, зануляет ячейку и возвращает строку. Выбрасывает EmptyStackException, если стек пуст.
Вспомогательные методы: peek() (просмотр вершины без удаления), isEmpty() (проверка top == 0), size() (возвращает top).
Программа проверки IP
Суть: Проверка строки регулярным выражением на формат X.X.X.X, где каждая группа X — число в диапазоне от 0 до 255.

Задание 5. Поиск всех слов, начинающихся с заданной буквы
Расширенный Stack и инвертор
Метод search: Ищет элемент с конца массива. Возвращает его позицию относительно вершины (1, 2...) или -1, если элемент не найден.
Метод printStack: Выводит в консоль текущее состояние массива элементов.
Инвертор строк (main): Разбирает исходную строку посимвольно, помещает каждый символ в стек через push(), а затем последовательно извлекает их через pop() до опустошения стека (isEmpty()). За счет принципа LIFO строка собирается в зеркальном порядке.
