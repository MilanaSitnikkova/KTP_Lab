Задание 1. Топ-10 часто встречающихся словКласс Queue (Очередь на основе FIFO)Структура: Односвязный список узлов Node (поля data и next). Ссылки на начало (head) и конец (tail) очереди, счетчик size.
Метод enqueue(item): Добавляет элемент в конец (tail). Если очередь пуста, head и tail указывают на один узел. При наличии элементов обновляет tail.next и смещает tail.
Метод dequeue(): Удаляет и возвращает элемент из начала (head). Указатель смещается: head = head.next. Если очередь опустела, tail зануляется. Бросает NoSuchElementException, если элементов нет.Вспомогательные методы: peek() (просмотр head.data), isEmpty() (head == null), getSize().

Суть: Считывание текстового файла, заполнение Map<String, Integer>, где ключ — слово, значение — частота. Далее выполняется сортировка по значениям и вывод 10 первых элементов.

Задание 2. Обобщенный класс Stack на основе массиваМетод инвертирования очереди (reverseQueue)
Логика разворота: Переворачивает порядок элементов в очереди с помощью стороннего стека (java.util.Stack).
Шаг 1: В цикле while (!queue.isEmpty()) элементы извлекаются через dequeue() и помещаются в стек через push().
Шаг 2: В цикле while (!stack.isEmpty()) элементы извлекаются из стека через pop() и возвращаются в очередь через enqueue(). За счет принципа LIFO порядок элементов меняется на противоположный.

Задание 3. Учет продаж в магазинеМетод циклического сдвига очереди (rotateQueue)Логика сдвига: Переносит $k$ элементов из начала очереди в её конец без использования сторонних коллекций.
Оптимизация: Если очередь пуста, $k = 0$ или $k$ кратно размеру очереди (k % size == 0), метод завершает работу.
Перенос: Вычисляется реальное число сдвигов k = k % size. В цикле for ровно $k$ раз подряд вызывается связка queue.enqueue(queue.dequeue()).Пример: Очередь [1, 2, 3, 4, 5] при $k = 2$ превращается в [3, 4, 5, 1, 2].
