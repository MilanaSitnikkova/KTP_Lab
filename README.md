Задание 1. Многопоточное вычисление суммы элементов массиваКласс BinaryTree (Базовые операции)
Структура: Дерево состоит из узлов Node (поля value, left, right).
Метод insert: Рекурсивно ищет место для вставки. Если новое значение меньше текущего узла — идет в левую ветвь (left), если больше — в правую (right). Дубликаты игнорируются.Метод search: Рекурсивно сравнивает искомое значение с текущим узлом. Двигается влево или вправо. Если доходит до null — возвращает false, при совпадении — true.
Программа вычисления суммы массива через ExecutorServiceСуть: Массив делится на равные части по количеству потоков. Каждая часть обрабатывается отдельной задачей в пуле ExecutorService. После завершения всех потоков главный поток суммирует полученные промежуточные результаты.

Задание 2. Многопоточный поиск максимума в матрицеСпособы обхода дерева (DFS)
Инфиксный (inOrderTraversal): Левое поддерево -> Текущий узел -> Правое поддерево. Выводит элементы бинарного дерева поиска в порядке возрастания.
Прямой (preOrderTraversal): Текущий узел -> Левое поддерево -> Правое поддерево. Применяется для копирования или сериализации структуры.
Обратный (postOrderTraversal): Левое поддерево -> Правое поддерево -> Текущий узел. Используется для удаления дерева или вычисления выражений.
Программа поиска максимума в матрице
Суть: Матрица разбивается на равные блоки (например, по строкам). Пул потоков ExecutorService параллельно ищет локальный максимум в своей части данных. В финале главный поток сравнивает результаты выполнения всех потоков и находит абсолютный максимум.

Задание 3. Моделирование работы грузчиков на складе
Метрики и поиск экстремумов в дереве
Поиск минимума (findMin): Смещение по ссылкам node.left в крайнюю левую точку до упора.
Поиск максимума (findMax): Смещение по ссылкам node.right в крайнюю правую точку до упора.
Подсчет узлов (countNodes): Рекурсивный расчет по формуле: $1 + \text{узлы слева} + \text{узлы справа}$.Глубина дерева (maxDepth): Вычисляет высоту самого длинного пути: $\max(\text{глубина левой ветки}, \text{глубина правой ветки}) + 1$.
Программа синхронизации работы грузчиков (LoaderRealization)
Суть: Создается класс LoaderRealization, реализующий интерфейс Грузчик (или Runnable). Три потока-грузчика параллельно берут товары со склада.
Синхронизация: С помощью потокобезопасных счетчиков или барьеров потоки суммируют вес переносимого груза. Как только общий вес достигает лимита в 150 кг, потоки приостанавливают сбор, имитируют транспортировку, разгружаются и возвращаются к работе. Управление потоками делегировано ExecutorService.
