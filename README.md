Описание работы абстрактного класса Book:
В рамках выполнения работы мы создали базовый абстрактный класс Book (Книга), который служит основой для создания различных типов печатных изданий.
Объяснение работы кода:
Поля и инкапсуляция: Мы определили скрытые (private) свойства для хранения названия (title), автора (author) и года издания (year). Для безопасного доступа к ним из других частей программы мы реализовали стандартные методы доступа — геттеры и сеттеры.

Конструкторы: Мы написали два конструктора: основной (принимает название, автора и год) и конструктор по умолчанию. Если данные не переданы, конструктор автоматически подставляет заглушки — «Неизвестно» и 0.
