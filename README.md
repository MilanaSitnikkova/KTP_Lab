Задание 1. Реализация HashTable (Метод цепочек)
Класс Entry (Запись)
Суть: Вспомогательный обобщенный класс <K, V> для хранения пары «ключ-значение».
Поля: private K key, private V value. Ключ защищен от изменений (нет сеттера).
Методы: Конструктор с параметрами, геттеры для ключа и значения, сеттер для значения.

Класс HashTable
Структура: Массив связанных списков LinkedList<Entry<K, V>>[] table. Дефолтный размер — 16. Поле size для учета количества элементов.
Хэширование: Метод hash(K key) берет Math.abs(key.hashCode()) % table.length для поиска индекса бакета.
Метод put(key, value): Находит бакет. Если ячейка пуста, создает список. Если ключ уже есть — обновляет значение. Если ключ новый — добавляет запись в конец списка и увеличивает size.
Метод get(key): Находит бакет, перебирает список. Возвращает value при совпадении ключа или null, если ключ не найден.
Метод remove(key): Находит бакет, ищет элемент в списке, удаляет его и уменьшает size.
Вспомогательные методы: size() (возвращает количество элементов) и isEmpty() (проверка на пустоту). В main реализовано тестирование всех операций, включая обработку дубликатов.

Задание 2. Работа со встроенным HashMap (Интернет-магазин)
Класс Product (Товар)
Поля: private свойства: name (название), desc (описание), price (цена), stock (количество на складе).
Методы: Конструктор со всеми параметрами, стандартные геттеры и сеттеры.
Переопределение: Метод toString() возвращает отформатированную строку с характеристиками товара и ценой в рублях.

Класс OnlineStore (Магазин)
Хранилище: Коллекция HashMap<String, Product> productMap, где ключ — артикул (String), значение — объект Product.
Метод addProduct: Добавляет товар в карту через put(article, product) с выводом подтверждения.
Метод findProduct: Ищет и возвращает товар по артикулу через get(article).
Метод removeProduct: Удаляет товар через remove(article). Выводит уведомление об успехе или ошибку «Товар не найден».
Метод showAll: Проверяет карту через isEmpty(). Если она не пуста, выводит все пары «артикул -> данные» с помощью forEach.
Интерфейс: В main запущен бесконечный цикл do-while со switch-case для консольного меню. Использует Scanner для пошагового ввода данных товара и управления магазином до ввода команды выхода (0).
