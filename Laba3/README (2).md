### Задание 1. Создайте класс HashTable, который будет реализовывать хэш таблицу с помощью метода цепочек.

#### Класс Entry (Вспомогательный)
Использование дженериков (Generics): При объявлении класса мы использовали универсальные параметры `<K, V>`, что позволяет динамически подставлять любые типы данных для ключа и значения.

Инкапсуляция данных: Мы определили скрытые свойства `key` и `value` с модификатором доступа `private`. Для безопасного считывания реализованы геттеры `getKey()` и `getValue()`, а для изменения значения — сеттер `setValue(V value)`. Ключ защищен от изменений, так как сеттер для него отсутствует.

Конструктор класса: Принимает два параметра (ключ и значение) и инициализирует ими внутренние поля создаваемого объекта пары.

#### Класс HashTable
Структура хранения данных: Хэш-таблица состоит из массива `table`, элементами которого являются связанные списки `LinkedList`, содержащие объекты класса `Entry<K, V>`. Размер массива по умолчанию задан константой `DEFAULT_CAPACITY = 16`. Добавлена переменная `size` для учета общего количества сохраненных пар.

Хэширование: Приватный метод `hash(K key)` вычисляет индекс бакета (ячейки массива). Он берет стандартный `key.hashCode()`, приводит его к модулю через `Math.abs` для исключения отрицательных значений и берет остаток от деления на длину массива.

Добавление элементов (метод put): Программа находит нужный индекс бакета по хэшу ключа. Если ячейка пуста, в ней инициализируется новый список. Если ключ уже существует в списке, его значение обновляется через `setValue()`. Если ключ уникален, новая запись `Entry` добавляется в конец списка, а счетчик `size` увеличивается.

Поиск элементов (метод get): Метод определяет индекс бакета и последовательно перебирает элементы списка. При совпадении ключей возвращается соответствующее значение `value`. Если ключ не найден, метод возвращает `null`.

Удаление элементов (метод remove): Метод находит целевой список по хэшу ключа. При обнаружении элемента с совпадающим ключом объект удаляется из структуры `LinkedList`, счетчик `size` уменьшается.

Вспомогательные методы и тестирование: Методы `size()` и `isEmpty()` возвращают текущее количество элементов и флаг пустоты таблицы. В методе `main` продемонстрирована базовая работа хэш-таблицы: добавление пар, обработка дубликата ключа (перезапись значения для "banana"), извлечение данных, удаление элемента и контроль размера структуры.

### Задание 2. Работа с встроенным классом HashMap (Вариант 2. Хранение товаров в интернет-магазине).

#### Класс Product
Свойства товара (Инкапсуляция): Определены закрытые свойства `private` для описания товара: название (`name`), описание (`desc`), стоимость (`price`) и количество на складе (`stock`). Для безопасного доступа и изменения данных реализованы стандартные геттеры и сеттеры.

Инициализация через конструктор: Конструктор принимает все четыре параметра и инициализирует внутренние поля объекта при его создании.

Строковое представление (Метод toString): Переопределенный метод `toString()` возвращает отформатированную строку с подробной информацией о товаре (наименование, описание, цена в рублях и остаток на складе) вместо хэш-кода.

#### Класс OnlineStore
База данных магазина: В качестве внутреннего хранилища используется коллекция `HashMap<String, Product> productMap`, где ключом является уникальный артикул товара (`String`), а значением — объект класса `Product`.

Управление каталогом (Основные методы): Метод `addProduct` добавляет новый товар в хэш-карту с помощью `put(article, product)`. Метод `findProduct` выполняет поиск и возвращает объект по его артикулу через `get(article)`. Метод `removeProduct` удаляет товар из коллекции методом `remove(article)`. Метод `showAll` проверяет карту через `isEmpty()` и последовательно выводит пары формата «артикул -> данные_товара» через лямбда-выражение `forEach`.

Интерактивное консольное меню: В методе `main` реализован бесконечный цикл `do-while` со структурой `switch-case`. С помощью `Scanner` программа принимает выбор действия. При создании нового товара приложение пошагово считывает свойства из консоли и передает созданный объект в `addProduct`. Остальные пункты меню вызывают методы поиска, удаления или отображения каталога. При выходе поток ввода закрывается через `scanner.close()`.
